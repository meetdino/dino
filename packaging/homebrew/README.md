# dino Homebrew tap

```sh
brew install meetdino/tap/dino            # the dino terminal, with the dino command
brew install meetdino/tap/dino-cli         # just the dino command and dinod
```

## Installed from asdf9384/tap?

This tap was `asdf9384/tap` through dino 0.1.5. Homebrew follows the move, but it stops trusting a
tap that moved: `brew upgrade` then skips dino, and `brew upgrade dino` says "Refusing to load cask
meetdino/tap/dino from untrusted tap meetdino/tap". Install it once more under the new name, which
trusts it and upgrades what you have:

```sh
brew install meetdino/tap/dino            # or meetdino/tap/dino-cli
```

The dino app updates itself either way; this only gets Homebrew following it again.

## Where these files come from

The files here are generated by dino's release script and point at the release assets on
[meetdino/dino's Releases page](https://github.com/meetdino/dino/releases). Edit them in the dino
repository (`packaging/homebrew/`), not here.
