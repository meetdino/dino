# dino Homebrew tap

```sh
brew install --cask asdf9384/tap/dino      # the dino terminal, with the dino command
brew install asdf9384/tap/dino-cli         # just the dino command and dinod
```

The files here are generated by dino's release script and point at the release assets in
[asdf9384/dino-releases](https://github.com/asdf9384/dino-releases). Edit them in the dino
repository (`packaging/homebrew/`), not here.
