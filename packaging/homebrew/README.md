# dino Homebrew tap

```sh
brew install meetdino/tap/dino            # the dino terminal, with the dino command
brew install meetdino/tap/dino-cli         # just the dino command and dinod
```

The files here are generated by dino's release script and point at the release assets in
[meetdino/dino-releases](https://github.com/meetdino/dino-releases). Edit them in the dino
repository (`packaging/homebrew/`), not here.
