# Getting help

- **A question, or stuck on something:** ask in
  [Discussions → Q&A](https://github.com/meetdino/dino/discussions/categories/q-a). Search first;
  someone may have asked already.
- **A bug:** in dino, **Help → Report a Bug…** opens the
  [bug form](https://github.com/meetdino/dino/issues/new?template=bug.yml) with your dino, macOS and
  agent versions filled in. `~/.config/dino/dinod.log` often says why.
- **An idea:** the [idea form](https://github.com/meetdino/dino/issues/new?template=feature.yml),
  or [Discussions → Ideas](https://github.com/meetdino/dino/discussions/categories/ideas) to talk
  it through first.
- **Something you made with dino:**
  [Discussions → Show and tell](https://github.com/meetdino/dino/discussions/categories/show-and-tell).
- **A security issue:** privately, never in an issue or discussion. See [SECURITY.md](SECURITY.md).
